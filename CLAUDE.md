# Doom (AirplaneMode app): notes for Claude

PrBoom+ 2.6.66 compiled to WebAssembly, served as static files by busybox httpd. The game
runs in the browser; the box only serves files. Plays Freedoom, the **Layover** episode (6
airport maps generated by `wad/`), and `.wad` files from Drop.

Part of AirplaneMode: the platform repo is `../airplanemode` (read its `CLAUDE.md` and
`docs/app-contract.md`; decision 0015 is this app). Drop is `../airplanemode-drop`.

## Layout

- `engine/`: `build.sh` (runs in the emsdk image), `patch.py` (string patches to PrBoom+,
  each asserted), `am_web.c` (JS-callable `am_key`, `am_mouse`, `am_state`,
  `am_save_config`; `am_wait_frame` yields to the browser each loop).
- `wad/`: Layover. `mapkit.py` (polygons -> sectors/lines, roles, validation, previews),
  `parts.py` (signs, desks, seats, ropes, carousels), `art.py` (textures/flats in code),
  `screens.py` (TITLEPIC, INTERPIC, M_DOOM, level names), `maps/mapNN.py`, `build.py`
  (UMAPINFO, PNAMES/TEXTURE1 merged with Freedoom's, zdbsp), `test_wad.py`.
- `web/`: `index.html` (launcher + game), `app.js` (downloads, Drop WADs, IDBFS, starts the
  engine), `touch.js` (touch controls), `style.css`.
- `tools/manifest.py` (file sizes for the progress bar), `tools/test_web.py`.

## Commands

```powershell
docker build -t airplanemode-doom:dev .               # everything (engine ~3 min the first time)
docker compose up -d --build                          # standalone -> http://localhost:8771
python wad/test_wad.py                                # map tools + every map validates (CI)
python tools/test_web.py                              # page checks (CI)
# iterate on maps without Docker (needs freedoom2.wad from the Freedoom zip; no nodes):
python wad/build.py --iwad freedoom2.wad --out raw.wad --preview build/preview --no-nodes
```

Look at `build/preview/mapNN.png` after changing a map, and refresh `docs/maps/` from them.

## Rules and gotchas

- **Doom's palette has no muted blues or teals**: they turn grey. Use the periwinkle ramp
  `(v, v, 255)`, pure blues (`NAVY = (0, 0, 155)`), greens, browns, greys. Check new art
  through the palette before trusting it.
- **Function-pointer signatures must match exactly in wasm** ("function signature mismatch"
  trap). `patch.py` fixes m_cheat.c's handlers; watch for this with any new C.
- `emscripten.h` defines `true`/`false` macros: include it after the Doom headers.
- Upstream PrBoom+ files mix CRLF; `patch.py` normalises before matching. This repo is LF
  (`.gitattributes`); Python on Windows writes CRLF in text mode, so write with `newline="\n"`.
- PrBoom+ shows `h` rows as `1.2*h` (Doom's tall pixels): the page asks for width `h*1.2*aspect`.
- Mouse/turn units: 65536 = a full turn (`cmd->angleturn -= mousex`).
- **Map rules (mapkit):** sectors must not overlap; anything inside a room is an `inset`
  (or `pillar`, or `door(..., parent=room)`). Doors face the room (front) with the door
  behind (back); lifts get 62 from below and 88 from above automatically. Things placed on a
  block taller than 24 count as stuck. Moving ceilings (crushers) need explicit upper
  textures. Monster closets/props: `name="block"` hides them from "unreachable" warnings.
- A new texture name must exist in `art.TEXTURES` or Freedoom's TEXTURE1 (build checks).
- Episode end: MAP06's mast opens via UMAPINFO `bossaction` (Cyberdemon on medium/hard,
  barons on easy); keep a boss of that type on every skill or the exit never opens.
- The page uses **relative URLs** only (a test checks); Drop is reached at `../drop/`.
- Keys the touch controls send must match PrBoom+'s defaults (a test checks).
